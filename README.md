# Team Lead Dashboard

Static web front end for the team-lead weekly review dashboard, served with GitHub Pages.

* This repository contains only the browser UI (`index.html`).
* The UI does nothing on its own: every request needs an access token, which you enter at sign-in. The token is sent only in the HTTPS request body.
* No credentials, reports, employee data or ticket data are stored in this repository.

For setup and operating details, see the project owner's internal documentation.
